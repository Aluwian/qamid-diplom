# Автотесты «Мобильный хоспис»

UI-тесты на Python + Appium + pytest. Отчёт — Allure.

## Что нужно заранее

- Android-эмулятор (в плане — Pixel 4, API 29; в критериях сдачи указан API 36 — запускать на том, что стоит у вас, и написать здесь факт).
- Приложение установлено на эмулятор.
- [Appium Server](https://appium.io) запущен (по умолчанию `127.0.0.1:4723`).
- Python 3, зависимости из `tests/requirements.txt`.
- Allure Commandline — чтобы открыть отчёт.

Логин: `login2`  
Пароль: `password2`

## Запуск

1. Включить эмулятор.
2. Запустить Appium.
3. В терминале:

```bash
cd tests
source python_venv/bin/activate
pytest -v
```

Один файл: `pytest -v test_login.py`  
Повтор упавших: `pytest -v --lf`

## Отчёт Allure

pytest пишет результаты в `tests/allure-results`.

Из папки `tests/`:

```bash
allure serve allure-results
```

Для сдачи упаковать отчёт в корень репозитория:

```bash
cd ..
zip -r allure-results.zip tests/allure-results
```

Если тест упал, в отчёт попадает скрин экрана до очистки и удаления тестовой новости.

## Если после Save своей новости нет в списке

Сохранение могло пройти, а карточки на первой странице нет: стенд общий, сервер отдаёт только первую страницу, сверху чужие записи и новости «на завтра». Это не ошибка локаторов. Свои `Автотест_…` можно удалить руками и прогнать тест ещё раз. Чужие новости не удалять.
